# Desafio Projeto Verão 21

Primeira demonstração navegável do aplicativo educativo. Abra `index.html` no navegador para testar.

## Implementado nesta etapa
- 21 missões com passos e progresso local.
- 10 receitas demonstrativas com ingredientes e preparo.
- 12 movimentos em rascunho para revisão profissional.
- Lista de compras interativa e impressão.
- Prévia dos bônus, planos e perfil.
- Layout responsivo.

## Ainda pendente
Esta **não é a versão de produção**. Faltam autenticação, banco de dados, acesso pago seguro, painel administrativo, conteúdo completo (30 receitas, 14 bebidas, 8 situações e marmitas), fotografias e ilustrações técnicas, áudio/vídeo, revisão profissional, checkout e testes de segurança. As marcações são salvas apenas no navegador. Não há integração ativa com a Lovable.

## Próximo passo para Lovable
Na Lovable, criar projeto e conectar GitHub pela integração disponível. A integração pode não aceitar importação direta de um repositório existente; nesse caso, será necessário migrar o código para o repositório sincronizado pela Lovable. Recomenda-se converter a demonstração em React/Vite e implementar backend, políticas de autorização e revisão de conteúdo antes de vender acesso.
